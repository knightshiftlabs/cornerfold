Check our claims

Every promise we make, and how to check it yourself.

You shouldn’t have to take a privacy promise on trust. Each claim shows how it is kept, the automatic test that fails if it stops being true, and how you can check it yourself. The tests run on every change, and their results are public on GitHub.

Your files never leave your device

How it’s kept. Everything happens in your browser. Cornerfold’s code has no way of sending data anywhere: no uploads, no requests, no beacons. The site’s security policy also tells your browser to block connections to every other website.

How it’s tested. Every tool is tested in a real browser, under the site’s real security policy, by adding, editing and exporting files. Each test fails if any request leaves the site, or if the site sends anything to itself except plain requests for its own files. A separate test fails if the code ever gains a way of sending data.

Check it yourself. Open your browser’s developer tools, choose Network, then add and export a file. You’ll see Cornerfold load its own files and nothing else.

No tracking, analytics or ads

How it’s kept. Cornerfold has no analytics or advertising code. Our host’s analytics and its network-error reports are switched off, and every page tells anything between us and you not to modify it, so nothing can be injected on the way.

How it’s tested. Every day, and after every change, an automatic check fetches the live site and fails if any page loads anything from another website, or if our host starts asking browsers to send reports elsewhere.

Check it yourself. View the source of any page. Every script and style comes from cornerfold.org.

The site runs exactly the public source code

How it’s kept. The source code is public on GitHub, and building it with the same tool versions produces the same files, byte for byte.

How it’s tested. The same daily check builds the code on GitHub and compares every file with the one cornerfold.org serves. Any difference, whether a file is changed or added, fails the check.

Check it yourself. With Node.js installed, download the code and run npm ci, npm run build and npm run check:live.

Passwords are never kept

How it’s kept. A password you type is used once, on your device, to open that file. Then it is forgotten.

How it’s tested. After a protected file is opened, a browser test searches everywhere a website can store data (storage, cookies, caches and the page itself) and fails if the password is there.

Check it yourself. Open a protected file, then look under Application or Storage in your browser’s developer tools.

Signatures are never kept

How it’s kept. A signature you make, whether drawn, typed or from a photo, stays in the open tab. It is added to the pages you export and forgotten when you close the tab.

How it’s tested. After a signature is made and used, a browser test searches everywhere a website can store data and fails if anything was saved.

Check it yourself. Sign something, then look under Application or Storage in your browser’s developer tools. Nothing has been stored. The only thing Cornerfold keeps, besides the app itself, is your look settings, and only if you change them in Appearance.

No accounts and no cookies

How it’s kept. There is nothing to sign in to, and Cornerfold sets no cookies.

How it’s tested. A browser test fails if the site sets any cookie.

Check it yourself. Look under Cookies in your browser’s developer tools. There are none for cornerfold.org.

Strict security settings

How it’s kept. The site sends strict security headers. They limit what a page may load and do, and stop other sites from framing it.

How it’s tested. Every browser test runs under these exact headers, and the daily check fails if the live site sends anything different.

Check it yourself. Run cornerfold.org through an independent scanner such as securityheaders.com.

It works offline

How it’s kept. After your first visit, the app keeps a copy of its own files, never yours, in your browser.

How it’s tested. Checked by hand before each release. An automatic test is planned but not built yet.

Check it yourself. Visit once, switch on airplane mode, then reload the page and use it.

If any of this is ever untrue

That would be a serious bug. Please tell us at security@cornerfold.org.

What these checks do not cover

Cornerfold is AI-coded: most of its code is written by Claude, an AI model from Anthropic, and reviewed and released by KnightShift Labs. The checks above show that the site runs the public source and that it makes no requests carrying your files. They are not an independent security audit, they cannot find every kind of bug, and the app may produce exports that are not exactly what you expected. Check important files before you rely on them.
